# Raw AI Elicitation Output

**Prompt:** "I'm building an app called an assignment task manager for students to track coursework across multiple classes. Elicit requirements for me — what should this app do?"

**Response:**

Here's a requirements elicitation for an assignment task manager:

**Core features**
- Users can register and log in (with email/password or SSO) so their data is private to them.
- Users can create assignments with title, course, due date, description, priority level (low/medium/high), and estimated time to complete.
- Users can categorize assignments by course, and courses can have color tags for visual organization.
- Users can mark assignments as not started / in progress / completed.
- Users receive push notifications or email reminders as due dates approach (e.g., 24 hours before).
- Users can attach files (PDFs, images) to an assignment, e.g., the assignment sheet or a draft.
- Users can view assignments in a calendar view as well as a list view.
- Users can sync assignments with Google Calendar or Outlook Calendar.
- Users can set recurring assignments (e.g., weekly reading responses).
- The app should support collaboration — students in the same class could share a course and see each other's public deadlines, or work on group assignments together.
- Gamification: streaks or badges for completing assignments on time, to encourage engagement.
- A dashboard/analytics view showing completion rate, average time-to-completion, and workload distribution across courses.
- Search functionality across all assignments by keyword.
- Offline support so students can view/update assignments without an internet connection, syncing when back online.
- The app should be available as a mobile app (iOS/Android) in addition to web.
- Dark mode and accessibility support (screen reader compatible).

**Non-functional considerations**
- The app should be fast and responsive.
- The app should be secure and protect user data.
- The app should be scalable to support many users.
- The app should have a clean, intuitive UI.
